🎟️ Tiket Konser Neon

Tugas Pemrograman Berorientasi Objek (PBO) tentang Graphical User Interface (GUI). Program menampilkan sebuah tiket konser bertema neon beserta tombol keluar.

📌 Deskripsi

Program ini membuat jendela GUI sederhana yang menampilkan tiket masuk NEON FEST 2026. Tiket berisi kode tiket, nama pemesan, band, jenis tiket, jumlah, dan total bayar. Tampilan memakai tema neon (ungu gelap dengan aksen pink dan cyan).

✨ Fitur
Tampilan tiket konser bertema neon.
Judul, isi tiket, dan tombol tersusun rapi memakai layout manager.
Tombol KELUAR untuk menutup program (event handling).
Data tiket mudah diganti lewat variabel di dalam kode.

🧩 Konsep PBO dan GUI yang Digunakan
Konsep	Penerapan di program
Top-level container	JFrame sebagai jendela utama
Intermediate container	JPanel untuk mengelompokkan komponen
Atomic component	JLabel, JTextArea, JButton
Layout manager	BorderLayout (kerangka utama) dan GridLayout (judul)
Inheritance (pewarisan)	TiketNeon extends JFrame
Interface	implements ActionListener
Event handling	Method actionPerformed untuk tombol KELUAR
